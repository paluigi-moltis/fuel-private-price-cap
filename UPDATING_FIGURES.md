# Updating the report figures and documents

This note is the working recipe for refreshing the numbered report images in
`output/figures/` and the two documents that quote their numbers
(`quick_notes.md`, `adoption/paper.tex`). Written for future conversations:
follow it top to bottom for a full refresh.

## 1. Updating the data from MongoDB

**Never run the full download.** The `prices` collection (~4M rows) gets
OOM-killed when fetched in one shot (`EXIT:137`). Use the incremental script:

```bash
cd /home/ubuntu/coding/fuel-private-price-cap
uv run python adoption/mongo_refresh_incremental.py
```

What it does:

- reads the latest date already present in `data/prices_raw.parquet` and
  fetches only **newer** days from MongoDB, in 10-day windows (match on the
  `date` field, ISO format);
- applies the same post-pipeline column mapping as the main pipeline
  (`id_impianto, date, fuel, prezzo, dt_comu`) and appends to the parquet cache;
- prints the new cache range at the end — verify it (e.g.
  `2026-07-01 -> 2026-10-12`).

Gotchas learned the hard way:

- The cache is the **post-pipeline** frame (snake_case names), not raw Mongo
  docs. The Mongo `date` field is the price date; `dtComu` (→ `dt_comu`) is a
  communication timestamp stored as string `'dd/mm/YYYY HH:MM:SS'` — do not
  try `date.fromisoformat` on it.
- Requires `.env` with `MONGO_URI` (loaded via `python-dotenv`).
- 13 Oct arrived mid-day on the 13th; if the last day looks partial, it may
  just not be in MongoDB yet. Rerun the script later rather than treating the
  partial day as final. If a partially-loaded last day did get into the cache,
  delete its rows from the parquet before refetching.

Figures 4–7 are generated by `make_maps.py` into `adoption/output/figures/`
(`map_adoption_share.png`, `map_pb_adoption_share.png`,
`amap_price_post7_ben/gas.png`) and copied into `output/figures/` with the
numbered names by `make_report_figs.py`'s `copy_fig`. Figures 1–3, 8–9 are
generated directly into `output/figures/`.

Key definitions baked into the figures:

- **Station-level adoption (maps 4–5):** a station is an adopter if it priced
  at or below the tax-adjusted cap on **any** post-cap day; each station is
  counted **once** via `id_impianto` regardless of fuel. Do NOT pool per-fuel
  shares — 99.6% of stations carry both fuels and 26.6% are discordant
  (diesel-yes/petrol-no), so fuel-share pooling wrongly scores them 0.5.
- **Adoption panel (fig 3, models):** at the *station–fuel unit* level
  (`at_cap` in `adoption_panel.parquet`), fuel- and date-adjusted threshold
  (gasolio cap 2.261 from 6 Oct).
- **Brand name:** the data value is `Agip Eni`; it is displayed as **Eni**.
  `make_report_figs.py` renames the column value on read. If brand charts ever
  lose the Eni line, check that the rename and the `BRAND_ORDER` filter agree
  (a label-only rename silently drops the line).

## 4. Documents to update after a data refresh

Two documents carry time-sensitive numbers and both must be updated together:

1. **`quick_notes.md`** (repo root) — the executive summary: compliance
   shares (first-day ~21%, by-day path, final-day), the 6 Oct diesel excise
   step, dispersion, brands, price levels (petrol 2.11→2.04, diesel
   2.24→2.25 EUR/l). Keep it short — it is the "what happened" note.

2. **`adoption/paper.tex`** — the full paper. Recurring spots that change with
   every refresh:
   - abstract/intro/conclusion: window length in days, any-day adoption share
     and unit count, final-day shares, median adoption day;
   - methods: "window runs from 1 July to <last date>", censoring date, panel
     unit count;
   - results §6: Cox/LPM coefficients (read fresh from
     `adoption/output/revision_cox.txt` and `revision_lpm.txt`);
   - §7 dispersion: SD rose in N of 220 cells, medians, map ranges (from
     `make_maps.py` log lines `saved ... | z: <min> - <max>`);
   - brand paragraph: final-day per-brand shares (from
     `output/tables/cap_compliance_daily_bandiera.csv`, tipo Stradale);
   - appendix map captions: date windows and definition wording.

   After editing, recompile:

   ```bash
   cd adoption
   pdflatex -interaction=nonstopmode paper.tex && biber paper && \
   pdflatex -interaction=nonstopmode paper.tex && pdflatex -interaction=nonstopmode paper.tex
   ```
   Check: 0 lines starting with `!`, 0 "undefined" reference/citation warnings.

Also touch up `adoption/README.md` (window dates in two places) and
`adoption/paper_draft.md` header when the window moves.

## 5. Workflow conventions

- Work happens on a fork branch (`fork` remote → `paluigi-moltis`, branch
  `feat/cap-adoption-drivers`); PRs target `paluigi/fuel-private-price-cap`.
  One PR per logical batch; earlier merged PRs just mean: start from the
  updated `main` (pull fork main first).
- Verify every figure visually after regenerating (legend present, lines
  present, labels above cap lines, x axis reaches the new last date) —
  silent empty-filter drops have happened.
- Recompute headline numbers from the parquet/CSV outputs rather than
  trusting memory; the numbers that move are: any-day unit share (~70%),
  final-day per-fuel shares, median adoption day, day-4 tercile gradient,
  Cox/LPM coefficients, SD-cells count, brand shares.
